# Oil Is Well (NWIS) prototype

Synthetic demonstration data only. Simulated eRTMAC feed. Not connected to Oil India Limited systems.

    npm install
    npm run dev

Open the printed localhost URL (default http://localhost:5173).

- src/data/wells.js: synthetic wells
- src/data/events.js: synthetic event repository (drives graph, formation intelligence, outcomes)
- src/app.js: UI logic (Foresight Flow, graph, formation, document review, replay)
- src/styles.css: styling
